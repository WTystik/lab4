# Аналитика задач Jira

Лабораторная работа № 4. Гарипов Р. Р., группа 5140904/60401.

Программа получает задачи Jira Cloud через REST API и строит шесть видов
графиков: время до закрытия, время в состояниях, созданные и закрытые задачи
по дням, показатели пользователей, трудозатраты и распределение по приоритетам.
Результаты сохраняются в HTML, PNG, JSON и CSV.

## Установка

Нужен Python 3.11 или новее. Команды выполняются из каталога проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

## Запуск на данных HELP

В `data/help` находится сохранённая выгрузка учебного проекта: шесть задач,
три из них закрыты. Для её обработки доступ к Jira не требуется.

```powershell
.\start.cmd --from-export data\help --output output
```

Результат открывается в `output/index.html`. На странице есть шесть разделов
и переключение отдельных состояний. Повторная обработка сохраняет дату
исходной выгрузки и отдельно записывает время расчёта.

## Подключение к Jira

Адрес сайта, JQL, закрытые статусы, часовой пояс и поле группировки задаются
в `config.toml`. Email Atlassian и API token передаются через переменные
окружения `JIRA_EMAIL` и `JIRA_API_TOKEN`.

После настройки учётных данных:

```powershell
.\start.cmd --output output-live
```

Клиент рассчитан на Jira Cloud. При временных ошибках выполняются повторные
запросы; поиск задач и история переходов загружаются постранично.

## Тесты и сборка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\build_release.ps1
```

Подготовлен 31 тест: 28 модульных и 3 интеграционных. Внешний сервер в тестах
не вызывается. Сборка запускает проверки, создаёт wheel и архив
`dist/jira-lab4-analytics-windows.zip` с конфигурацией, инструкцией и `start.cmd`.

## Файлы проекта

- `jira_analytics` — клиент API, расчёты, графики и командный запуск;
- `tests` — модульные и интеграционные проверки;
- `data/help` — исходные данные для повторного расчёта;
- `report` — отчёт в формате DOC;
- `dist` — собранный дистрибутив.

Окружение, результаты запуска, журналы и локальные учётные данные исключены
из Git через `.gitignore`.
