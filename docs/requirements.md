## Обязательная функциональность

| Пункт ТЗ | Реализация | Проверка |
|---|---|---|
| Приложение на языке высокого уровня и соединение с Jira через REST API | Python 3.11+, клиент `JiraClient`, HTTPS, Basic Auth, `/rest/api/3/search/jql`, постраничная история | `test_client.py`; фактическая выгрузка проекта HELP |
| Гистограмма от создания до закрытия, только закрытые задачи | `closed_at`, `analyze`, `01_lifetime.png`; X — время, Y — количество | Выбор только закрытых, финальное закрытие после переоткрытия, недопустимость подмены датой updated |
| Время по каждому состоянию, отдельная диаграмма каждого состояния | `status_hours`, `02_status_XX.png`; единая единица, сумма повторных посещений, нули для непосещенных состояний | Повторные переходы, нулевые длительности, сумма состояний равна жизненному циклу |
| Созданные и закрытые по дням, дневные и накопительные значения | `daily`, `03_daily.png`; две панели, общая календарная ось | Пустые дни, UTC+3, равенство итогов числу событий |
| Исполнители и репортеры, топ-30 | `user_counts`, `04_users.png`; X — количество, Y — пользователь | Разные аккаунты с одним именем, один пользователь в двух ролях, ограничение 30 |
| Трудозатраты из учета времени, только закрытые | `timespent`, `05_logged.png`; часы хранятся в модели, ось отображается в подходящей единице | Отсутствие записи отличается от нуля; трудозатраты сохраняются даже при неизвестной дате закрытия |
| Количество задач по степени серьезности | `severity_field`, `06_severity.png`; в проекте HELP используется `priority` | Группировка всех задач; отдельная категория для незаполненного поля |

## Структура и надежность

- Сеть, аналитика, построение графиков и CLI разделены по модулям.
- Публичные функции и методы документированы; названия отражают назначение.
- Обрабатываются ошибки авторизации, временные HTTP 429/5xx, сетевые ошибки, неверный JSON, неполные страницы и некорректные длительности.
- Поиск и история читаются постранично; выполняются ограниченные повторы временных ошибок.
- В журнал не выводится API token. Результат содержит предупреждения, если закрытие нельзя датировать.
- Тесты не обращаются к внешней Jira. Режим `--fixture` помечается как ДЕМО; `--from-export` сохраняет происхождение ранее полученных данных.

## Данные и область применения

В задании Apache Kafka и Hadoop HDFS предложены словами «можно взять». Приложение проверено на собственном проекте HELP в Jira Cloud: 6 задач, 3 закрытые, 1 пользователь. ТЗ не задает минимальное число задач и не требует ровно 30 пользователей при меньшем числе доступных аккаунтов.

Клиент рассчитан на **Jira Cloud**. Он не объявляется универсальным клиентом Jira Server/Data Center. Данные учебного проекта не являются статистически представительной выборкой для оценки реальной службы поддержки; программа отображает фактическое число наблюдений.

При проверке итоговых графиков используется сохраненная реальная выгрузка HELP. Подключение к серверу и исходные состояния подтверждены снимками первоначального запуска и фильтром Jira. Секретные данные и выгрузки не публикуются в Git.
