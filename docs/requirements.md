## Критерии оценки

- Шесть видов графиков: шесть разделов HTML; у каждого состояния собственная диаграмма.
- Git: исходники, тесты и механизм сборки находятся в репозитории.
- Не менее пяти модульных тестов: 37 модульных и 4 интеграционных, всего 41.
- Механизм сборки: `build_release.ps1`, тесты → wheel → ZIP.
- Конфигурация и запуск: `config.toml`, `install.cmd`, `start.cmd`, wheel и README в дистрибутиве Windows.

## Получение и границы данных

Основной источник — https://issues.apache.org/jira, проект KAFKA. Ключ проекта можно заменить на HDFS или любой другой доступный проект Apache Jira через `--project`, в том числе ссылкой на страницу проекта. Без JQL загружается весь проект; ограничений по количеству задач в клиенте нет. Все страницы поиска обрабатываются, число записей и полнота истории контролируются.

Фильтр `--jql` ограничивает выборку явно и записывается в результат. Временные графики учитывают только сейчас закрытые задачи; распределение приоритетов и пользователи — все полученные задачи. Топ-30 означает максимум 30 пользователей.

Публичные задачи Apache читаются без регистрации и токена. Старые учётные данные Cloud не передаются на Apache. При запрете доступа, ошибке сети, неполной истории или недопустимой дате программа сообщает об ошибке, а не заменяет данные фикстурой.

Если в проекте отсутствуют записи учёта времени, пятый график сообщает об отсутствии данных. Выдуманные трудозатраты в отчёт не добавляются. Повторная обработка реального экспорта отмечается отдельно; искусственный набор помечается ДЕМО.
